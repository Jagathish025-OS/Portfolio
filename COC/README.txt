Jagathish COC Frontend V12

Base mode is now an AI Creative Base Lab.

Creative directions:
AI Surprise, Fun, Character, Creature, Icon/Symbol, Shape/Pattern,
Maze/Puzzle, Meme/Troll, Theme, Fantasy, Letter/Number, Abstract,
Experimental.

Community directions:
War, Farming, Trophy, Hybrid.

AI flow:
1. Select Town Hall.
2. Select an AI creative direction or a community purpose.
3. For AI directions, optionally describe an idea.
4. AI returns three concepts.
5. Choose a concept.
6. Server renders a structured blueprint.
7. The UI clearly states that a creative blueprint is not an official OpenLayout export.
